# 投稿アプリの構造図

| まとまり       | 実物の場所                                            | 置くもの                                                    |
| -------------- | ----------------------------------------------------- | ----------------------------------------------------------- |
| ルーティング   | routes/web.php                                        | どのURLがどのコントローラーを呼ぶか、ログインが必要かどうか |
| コントローラー | app/Http/Controllers/PostController.php               | 受け取った内容の処理、画面の表示、どんな値まで受け取るか    |
| 認可           | app/Policies/PostPolicy.php                           | 誰がその投稿を編集・削除してよいか                          |
| モデル         | app/Models/User.php・Post.php・Category.php           | データの読み書き、テーブルどうしのつながり                  |
| ビュー         | resources/views/posts/index.blade.php・edit.blade.php | 画面に並べるもの                                            |
| データベース   | users・categories・posts テーブル                     | 覚えておく中身                                              |

## 認可を独立させた理由

投稿の編集・削除の権限に関する決まりは、画面やデータの持ち方とは異なるきっかけで変更されるため、認可として独立したまとまりにした。
