# 投稿アプリ CRUD表



|ID|機能|主な利用者|
|:------|:--------|:---------|
|F-01|新規登録|ログイン前ユーザー|
|F-02|ログイン|ログイン前ユーザー|
|F-03|投稿の一覧表示|ログインユーザー|
|F-04|投稿の編集|ログインユーザー（自分の投稿のみ）|
|F-05|投稿の削除|ログインユーザー（自分の投稿のみ）|
|F-06|ログアウト|ログインユーザー|


|機能|ユーザー|カテゴリ|投稿|
|:----|:----|:----|:-----|
|F-01 新規登録|C|-|-|
|F-02 ログイン|R|-|-|
|F-03 投稿の一覧表示|R|R|R|
|F-04 投稿の編集|R|R|U|
|F-05 投稿の削除|R|-|D|
|F-06 ログアウト|-|-|-|

ユーザーは更新(U)・削除(D)の機能がありません
カテゴリは作成(C)・更新(U)・削除(D)がなく、投稿には作成(C)の機能がありません。
また、ログアウトは今回の３つのデータには触れないため、すべて「-」になります。
