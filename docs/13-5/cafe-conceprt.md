# CAFE モバイルオーダーアプリ 概念モデル

## エンティティ一覧

エンティティ|何を覚えておくものか|主な属性
:--------|:-------|:-------
商品|その日に出すドリンクやフード|商品名・値段・短い説明・区分・その日売れるかどうか
注文|お客さまが1回で出した注文|注文番号・合計金額・受け取りの状態・注文日時
注文明細|お客さまが1回で出した注文の中の商品1種類分|個数・商品1個の値段

#### エンティティにしなかったもの
- カート：ログインしていない方も注文ができ、次にアプリを開いた時まで残しておく必要もないため、保存するエンティティにしませんでした。
- お客さま：会員登録をしない想定で、ログインせず誰でも注文できるため、お客さま情報を保存するエンティティにはしませんでした。
- 店員：1台のタブレットを共通で使い、同じアカウントで操作する想定のため、店員ごとの情報を保存するエンティティにはしませんでした。
