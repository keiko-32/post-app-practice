# カフェ/モバイバルオーダーアプリ画面一覧

## 画面一覧

|ID|画面名|役割|主な利用者|
|:-----|:-----|:-----|:-------------|
|SC-01|メニュー画面|その日のドリンクとフードの商品一覧を見て商品と個数を選択する。（最初に開く画面）|お客さま|
|SC-02|カート画面|選んだ商品と個数、合計金額を確認する|お客さま|
|SC-03|支払い画面|外部決済サービスに支払いを依頼し、その結果を受けとる|お客さま|
|SC-04|注文完了画面|注文を受け付けたことと、注文番号を知らせる|お客さま|
|SC-05|注文状況画面|注文番号で、注文がお店に届いているかを確かめ、取り消す|お客さま|
|SC-06|受け取り前の注文を、注文番号をともに一覧で見る（最初に開く画面）|店員|
|SC-05|注文詳細画面|注文した商品と個数を確認し、受け渡し済みにする|店員|
