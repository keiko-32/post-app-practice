# 投稿アプリの画面一覧

## 画面一覧

|ID| 画面名|役割|主な利用者
|:---|:-----|:-----------|:-----------|
|sc-01|つぶやき投稿アプリ画面|ログイン前の利用者にはログイン・アカウント作成への案内を表示し、ログイン済み利用者にはタイムラインへの案内とログアウト操作を表示する（最初に開く画面）|ログイン前ユーザー・ログイン済みユーザー|
|sc-02|ログイン画面|メールアドレスとパスワードを入力してログインする。入力エラーがある場合はエラーメッセージを表示する。初めての利用者にはアカウント作成への案内を表示する。テスト用アカウント情報も表示する|ログイン前ユーザー|
|sc-03|アカウント作成画面|名前・メールアドレス・パスワード・確認用パスワードを入力してアカウントを作成する。入力エラーがある場合はエラーメッセージを表示し、入力済みの値は再表示する。登録済みの利用者にログイン画面への案内を表示する|ログイン前ユーザー|
|sc-04|投稿一覧画面|ログイン中の利用者情報と投稿一覧を表示する。投稿がない場合はメッセージを表示する。各投稿には投稿者名・投稿日時・カテゴリ・タイトル・本文を表示し、権限がある投稿には編集・削除操作を表示する。ログアウトもできる|ログイン済みユーザー|
|sc-05|投稿編集画面|既存の投稿内容を表示し、タイトル・カテゴリ・本文を編集して更新する。入力エラーがある場合はエラーメッセージを表示し、入力済みの値を再表示する。更新せずに一覧画面へ戻ることもできる。|ログイン済みユーザー|
