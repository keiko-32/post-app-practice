# AIチェック結果

対象：経費精算アプリ設計書一式

| AIから来た質問 | 判定 | やったこと |
|---|---|---|
| 申請者ごとの承認者は、どのように決めるのか？ | 依頼者に確認 | 承認者の割り当て方法を確認事項（Q-01）に追加する |
| 状態遷移図と状態遷移表で、差し戻しの流れが一致しているか？ | 設計書に答えあり | 状態遷移表の内容に合わせて、状態遷移図を修正する |
| 申請画面の5行は、1回の申請でまとめて登録するのか、別々に登録するのか？ | 依頼者に確認 | 申請単位を確認し、画面・API・DBの設計を統一する |
| API-03・API-04の送受信内容や操作の区別は明確か？ | 自分たちで決める | 詳細取得の返却項目と、承認・差し戻し・再提出の指定方法を追記する |
| 差し戻し後の再提出で、過去の差し戻し理由や判断履歴をどう扱うか？ | 依頼者に確認 | 履歴の保存方法、差し戻し回数の上限、再提出されない場合の扱いを確認事項に追加する |
