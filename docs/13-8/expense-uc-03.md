#### UC-03：申請内容の確認・承認

- **アクター**: 承認者
- **事前条件**: 承認者に承認待ちの申請が届いている状態

- **基本フロー**:
    -   1. 承認待ちの一覧を開く
    -   2. システムが承認待ちの申請一覧を表示する
    -   3. 承認者が確認したい申請を選択する
    -   4. システムが選択された申請の詳細を表示する
    -   5. 承認者が申請内容を確認する
    -   6. 承認者が承認ボタンを押す
    -   7. システムが申請を承認済みに変更する
    -   8. システムが承認済みの申請を承認待ち一覧から非表示にする

    **代替フロー**:

    ### 5a. 差し戻し理由が入力されている場合
    -   1. 承認者が差し戻し理由を入力する
    -   2. 承認者が差し戻しボタンを押す
    -   3. システムが申請の状態を「差し戻し」に変更する
    -   4. システムがその申請を承認待ち一覧から取り除く

    ### 5b. 差し戻し理由が空欄の場合
    -   1. 承認者が差し戻し理由を入力せずに差し戻しボタンを押す
    -   2. システムは差し戻し理由の未入力を検知し「差し戻し理由を入力してください」と表示する
    -   3. システムは差し戻し処理を行わず申請の状態を変更しない

- **事後条件**:
- 承認した場合： 申請の状態が「承認済み」に変更され、承認待ち一覧から非表示になる
- 差し戻した場合： 申請の状態が「差し戻し」に変更され、承認待ち一覧から非表示になる
- **受け入れ条件**:
    - [ ] 承認者が申請詳細画面で、最大5件までの各経費明細の日付、金額、利用目的、費目を確認できる
    - [ ] 承認者が承認ボタンを押すと、申請の状態が「承認済み」になり承認待ち一覧から非表示になる
    - [ ] 承認者が差し戻し理由を差し戻すと、申請の状態が「差し戻し」に変更され承認待ち一覧から非表示になる。また申請者が自分の申請一覧から差し戻し理由を確認できる
