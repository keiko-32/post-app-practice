## 経費精算アプリ画面一覧

## 画面一覧

| ID    | 画面名           | 役割                                                                                               | 主な利用者     |
| :---- | :--------------- | :------------------------------------------------------------------------------------------------- | :------------- |
| SC-01 | ログイン画面     | メールアドレスとパスワードでログインする （最初に開く画面）                                                              | 申請者・承認者 |
| SC-02 | 申請一覧画面     | 自分が提出した申請と申請状況を確認し、新規申請や差し戻しされた申請の修正に進む                     | 申請者         |
| SC-03 | 経費申請画面     | 最大5件までの各経費明細の日付、金額、利用目的、費目を入力あし提出する                                     | 申請者         |
| SC-04 | 承認待ち一覧画面 | 承認待ちの申請を一覧表示し、確認する申請を選択する                                                 | 承認者         |
| SC-05 | 申請詳細画面     | 各明細の日付・金額・費目・利用目的を確認し、承認または差し戻しを行う。差し戻す場合は理由を入力する | 承認者         |
