経費申請システム API設計書

## エンドポイント一覧

| ID     | メソッド | エンドポイント             | 何をするか              | 認証 |
| :----- | :------- | :------------------------- | :---------------------- | :--- |
| API-01 | POST     | /api/expenses              | 経費の申請を提出する    | 必要 |
| API-02 | GET      | /api/expenses              | 申請の一覧を取得する    | 必要 |
| API-03 | GET      | /api/expenses/{申請の番号} | 申請1件の詳細を取得する | 必要 |
| API-04 | PUT      | /api/expenses/{申請の番号} | 申請1件を書き換える     | 必要 |

#### API-01 経費の申請を1件提出する

- **メソッドとエンドポイント**: POST /api/expenses
- **認証**:必要
- **送るもの**: 本文で、使った日と、金額、費目と利用目的
- **返すもの（うまくいったとき）**: 201。登録した申請1件（申請の番号・使った日・金額・費目・利用目的・申請の状態）
- **返すもの（うまくいかなかったとき）**: 401（ログインしていないとき）/422（送ったものに不備があるとき）

#### API-04 申請1件を書き換える

- **メソッドとエンドポイント**: PUT /api/expenses/{申請の番号}
- **認証**:必要
- **送るもの**:URLに申請の番号。本文で、申請者が出し直すときは書き直した中身（使った日、金額・費目・利用目的）、承認者が判断するときは承認か差し戻しかと、差し戻しの理由
- **返すもの（うまくいったとき）**:200。書き換えたあとの申請１件（申請の番号・使った日・金額・費目・利用目的・申請の状態・差し戻しの理由）
- **返すもの（うまくいかなかったとき）**:401(ログインしていないとき)/403（自分に関わりのない申請のとき）/404(その申請が見つからないとき)/422（送ったものに不備があるとき、または申請中でない申請を判断しようとしたとき）

## エラーレスポンス一覧

| 起きること                                                                   | ステータスコード | 返すもの                         |
| ---------------------------------------------------------------------------- | ---------------- | -------------------------------- |
| ログインしていない                                                           | 401              | ログインが必要である旨の文言     |
| ログインしているけれど書き換えや申請を見ようとした時その操作をする権限がない | 403              | 権限がない旨の文言               |
| 指定した番号の申請がみつからない                                             | 404              | データがみつからない旨の文言     |
| 入力内容に不備がある                                                         | 422              | 不備のあった項目とその理由の文言 |
| 申請中ではない申請を承認・差し戻ししようとする                               | 422              | すでに判断が済んでいる旨の文言   |

## API-02：申請一覧を取得する

- **メソッドとエンドポイント**: GET/api/expenses
- **認証**: 必要
- **取得するもの**:
- 申請者の場合： 自分が出した申請
- 承認者の場合： 自分が出した申請と、自分宛ての承認待ちの申請
- **補足**: 申請者用と承認者でエンドポイントを分けず、ログインしていている人の立場によって取得する内容を変える。
