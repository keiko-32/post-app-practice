# 経費申請画面の画面項目定義

|項目名|種類|必須|内容|備考|
|------|------|-------|-----|----|
|画面見出し|表示|-|「経費を申請する」|-|
|日付|入力|必須|経費を立て替えた日を入力する|支払日・利用日|
|利用目的|入力|必須|利用した目的を入力する|-|
|費目|選択|必須|交通費・書籍代・会議費・その他の中から１つ選択する|-|
|金額|入力|必須|経費を立て替えた金額を入力する|-|経費明細1件あたり5万円以下。税込として扱う想定（Q-05確認中）
|差し戻し理由|表示|-|承認者が入力した差し戻し理由を確認する|差し戻された申請の修正時のみ表示。閲覧のみ。|
|申請・再提出ボタン|ボタン|-|入力した経費明細を新規申請する。差し戻し修正時は修正した内容を再提出する|新規申請時は「申請する」・差し戻し修正時は「再提出する」と表示する|
|キャンセルボタン|ボタン|-|入力を中止して申請一覧画面に戻る|入力内容は申請しない|
